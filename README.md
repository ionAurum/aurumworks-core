# Aurumworks Core

A Unity package (Unity 6000.0) shared by the Aurumworks games and by Attune: settings stored
through one class, build info, sound cues and a sound player, a UI kit and theme for menus built
in code, the menu shell (main menu, settings, session menu) and a self-test harness.

It depends on uGUI and the Input System (TextMeshPro comes with uGUI).

## Install

In `Packages/manifest.json`, take a tagged version by git URL:

```json
"com.aurumworks.core": "https://github.com/ionAurum/aurumworks-core.git#v0.1.0"
```
